# 图文规范 · Product Hunt 推荐组图

三套视觉系统(teardown 默认 + guizang 移植的 swiss/editorial),瘦身为 Product Hunt 专属。**表达优先**:不是把文字塞进海报,而是把榜单变成一个清晰的视觉叙事。每张卡都要让观者一眼看懂「为什么这个产品值得看」。

## 产出形态

一组小红书 3:4 竖版组图(1080×1440),一个 HTML 里多个 `.poster.xhs`:

1. **封面页**(`xhs-cover`):品牌页眉 + 大标题 + 一句话钩子 + 本期看点目录。
2. **产品页**(`xhs-<rank>`):每产品一页,讲清「为什么值得看」。
3. **总结页**(`xhs-summary`):一句话收尾 + 票数榜 + 完整榜单链接。

## 视觉系统:三选一,一套到底

**不要混搭。** 一套组图只选一个风格模式。选风格按「你想要这篇读起来什么气质」。

### Teardown 产品拆解(默认,小红书原生)
暖橙主色、圆角卡片、分节内容块,信息密度高、页面吃满。产品页固定结构:

1. 页眉:Product Hunt 珊瑚圆 P 标 + 「产品拆解」品牌行 + 排名 No.N
2. 产品头:logo + 名称 + 一句话卖点(橙)
3. 引入段
4. 分节「哪些人需要它」:双卡(适合谁用 / 啥时候用得上)
5. 分节「跟竞品比好在哪」:浅橙对比块(● 列表)
6. 「💡 简单总结」浅橙块
7. 底栏:数据来源(产品链接)+ 票数 + 评论 + 发布日 + 本期排名

teardown 硬规则:页面吃满不留大空白;分节标题左橙条;底栏信息完整;页眉 logo 用官方珊瑚圆 P。

### Swiss 瑞士(工程冷感)
数据、决定感。4 个 accent:

| accent | 色值 | 适用 |
|---|---|---|
| `ikb` | `#002FA7` 克莱因蓝 | 默认,AI/科技/产品 |
| `lemon-yellow` | `#FFD500` 柠檬黄 | 年轻/消费/活泼 |
| `lemon-green` | `#C5E803` 柠檬绿 | 未来/新锐 |
| `safety-orange` | `#FF6B35` 安全橙 | 风险/决策点 |

Swiss 硬规则:无圆角、无阴影、无渐变;只用一种 accent;`--accent-on` 决定 accent 上文字颜色;越大越细(≥200px 用 weight 200)。

### Editorial 杂志 × E-ink(专栏感、慢节奏)
衬线 + 纸墨 + 杂志结构。6 个主题:

| theme | 底色 | 适用 |
|---|---|---|
| `indigo-porcelain` | 靛蓝 `#315d93` | 默认,科技/研究/冷静分析 |
| `ink-classic` | 中性墨 `#111` | 商业评论/产品思考 |
| `forest-ink` | 森林绿 | 自然/可持续发展 |
| `kraft-paper` | 牛皮纸棕 | 观点/手工/个人笔记 |
| `dune` | 沙丘 | 设计/克制美学 |
| `midnight-ink` | 暗金(唯一暗色) | 内容本身偏暗时 |

Editorial 硬规则:靠衬线 + 字号层级立住,**不用卡片背景**;每页保留 `grain`/`paper-wash` 氛围层;细字重(500 不是 900)、宽字距。

## 排版铁律

1. **越大越细。** 展示标题用轻字重;小字才用重字重。禁止「大字号 + 粗字重」。
2. **展示标题有硬上限**(xhs 3:4):最多 **2 行**,单行 ≤ **8 字**。超了就压缩文案,不要缩正文字号。
3. **正文最小可读字号**:body ≥28px、lead ≥30px、caption/kicker ≥20px、meta/label ≥20px(手机缩放后仍可读)。塞不下就删文案,不缩字号。
4. **卡面包满 ≥75%。** 3:4 卡内容(文字+图+数据)必须覆盖画布高度 ≥75%;禁止用 `<div style="flex:1">` 上下夹击把内容塞到中段。允许封面/总结这种「宣言式」页面留白(hero statement 自带呼吸)。
5. **editorial 用 `grain`/`paper-wash`**,不交纯色平底;Swiss 用纯色块 + 发丝线 + 网格节奏;teardown 用圆角卡片 + 浅橙块,页面吃满。
6. **编号/数字**用等宽对齐(mono)。

## 反模式(主动拒绝)

- **swiss/editorial 无 emoji**;teardown 仅保留参考版式的 💡 总结标,不另加。
- **无任意装饰 SVG**(blob、雨滴、贴纸、随手画的圈)。页眉 Product Hunt 标是品牌标,不算装饰。
- **无嵌套卡片 / SaaS 拼盘。** 每一页只有一个清晰的视觉主张。
- **产品 logo 不单独占一栏**(swiss/editorial 用 `.ph-head` 并排;teardown 用 `.td-head` 并排),不裁切 logo(contain)。
- **不编造数据。** 票数/评论/排名/发布日一律来自 `fetch-producthunt.mjs` 返回的真实值,绝不造假。
- **不把「制作要求」写成观众可见文案。** 卡上的字必须是用户真的会给观众看的内容。
- **底栏信息完整**:数据来源(带产品/榜单链接)+ 票数 + 评论 + 发布日 + 排名,不缺失。

## 一致性检查(交付前逐条过)

- 一套卡只用一个风格/主题。
- 展示标题 ≤2 行、单行 ≤8 字(swiss/editorial)。
- 卡面包满 ≥75%,无溢出。
- 票数/评论/排名与 data.json 一致,无编造。
- 页眉 logo 正确(teardown 为珊瑚圆 P),底栏信息完整。
